# Persona Manager

> SillyTavern 扩展 · Persona 人设管理 / 对比 / 重复检测

当前版本：**v1.11.1**。更新内容见 [CHANGELOG.md](CHANGELOG.md)。

Persona Manager 是一个 SillyTavern 扩展，帮助你浏览、对比、清理 Power User 模块里堆积的 Persona（人设）。

支持以下场景：

- **同名区分**：同一个人设名 + 不同头像时，用备注/标题做次行小字区分
- **重复检测**：按规范化后的描述找出重复人设，不要求同名
- **高度相似**：用 bigram 相似度找出描述高度重合的人设
- **跨结构对比**：低相似度或结构差异大时，提取共同片段（数字、短语、专名）做高亮
- **删除人设**：列表里直接删除（带二次确认），写回 `power_user.personas`
- **编辑人设**：按 ID 写回；保存失败保留草稿，检测其他窗口的并发修改
- **批量整理**：只处理所选人设的分类和标签，可添加、删除、替换或清空标记，列表旁的「＋」可新建条目
- **采纳片段**：可修改片段、指定锚点并预览完整结果和前后差异
- **缝合工作台**：按段落或按行选择，双向传递、全文编辑、撤销/重做，只保存改动的一侧
- **字段缝合**：按 Markdown 章节、YAML/JSON 字段决定保留目标、采用来源或手动合并
- **草稿与历史**：编辑、采纳、缝合自动暂存；保存前后留版本，可对照回退并查看片段来源
- **资料备份**：导出/导入组织资料、草稿、历史、来源、主题配置与人设文字快照
- **四种主题**：粘土拟态、吉卜力风格、水彩艺术、少女漫画，分别自定义配色
- **多对象对比**：选 2~N 个一起对比，切换基准 / 对象，左边章节对齐 / 跨结构高亮两种模式自动切换

## 安装

**方式 1 · 扩展管理面板（推荐）**

酒馆主菜单 → Extensions → Install Extension → 粘贴仓库地址：

```
https://github.com/TokkiO-O/persona-manager
```

**方式 2 · 手动**

```bash
# 1. 下载最新 zip
curl -L -o persona-manager.zip \
  https://github.com/TokkiO-O/persona-manager/archive/refs/heads/main.zip

# 2. 解压到酒馆第三方扩展目录
unzip persona-manager.zip
mv persona-manager-main \
   <SillyTavern>/data/default-user/extensions/third-party/Persona\ Manager

# 3. 刷新酒馆页面
```

通过扩展管理器或 git 安装时请保留 `.git`，酒馆需要它识别和更新扩展。ZIP 安装采用手动覆盖更新。更新后刷新页面，手机端可关闭旧标签再重新打开酒馆。

## 使用

进入 **用户设置 → Persona 管理** 区块（扩展会在面板顶部注入入口按钮），或者在浏览器控制台执行 `openPersonaManager()`。

主界面有 9 个页签：

| Tab | 作用 |
|---|---|
| 全部 | 网格列出所有人设 |
| 同名 | 名称规范化后相同的人设分组 |
| 完全重复 | 描述规范化后相同的人设分组 |
| 高度相似 | 描述相似度 ≥ 阈值的成对列表 |
| 分类 | 管理分类并分组浏览 |
| 标签 | 创建标签、管理打标、筛选人设 |
| 回收站 | 恢复已删除人设的文字资料 |
| 资料 | 工作草稿 / 历史版本 / 片段来源 / 完整备份 |
| 设置 | 四种主题与自定义配色 / 匹配阈值 / 更新检查 |

### 对比

1. 选 2~N 个 Persona（每张卡片左侧复选框）
2. 底部出现"开始对比"按钮
3. 在对比页：
   - **顶部基准栏**：切换基准人设
   - **对象栏**：点击切换当前对比对象
   - **图例**：颜色含义见页面底部
   - **结构差异大**时自动切到"跨结构模式"，只标共同片段
   - **结构相似**时按章节对齐做精确 diff

共同片段和目录定位只滚动正文，主窗口跟随手机可视区域的大小与偏移。正文滚动时仍能使用顶部关闭和对比返回入口，退出对比后窗口恢复完整的屏幕范围。

### 编辑 / 删除

勾选多个人设后，底部「批量整理」可同时调整分类和标签。窗口内切换「分类 / 标签」，在原有的「处理方式」下拉框选择操作，不额外增加底栏按钮。

- 添加、删除所选人设的标记、替换、清空：所有操作都只修改选中的人设，分类／标签本身及其他人设的标记保留；默认添加并保留原有内容。
- 新增分类／标签：在添加或替换模式下，点击现有条目旁的「＋」展开新建表单。创建后自动选中并收起表单，标签可自选颜色。

切换分类／标签时保留选择、处理方式以及未完成的新建名称和颜色。底部汇总待应用操作，点击「应用整理」一次保存两类改动，正文保留。新建条目本身会立即保存，点击应用后才将其添加到所选人设；取消时不应用标记改动，保存失败时两类归属一起回退。

编辑器右上角可以直接切换「全屏 / 弹窗」。全屏铺满可视区域并收起名称，「名称」按钮可展开改名。手机点击正文后收起名称，键盘弹出时进一步隐藏说明和次要工具，保留正文、保存和关闭；可见高度很小时保存移到顶部，草稿继续自动保留。

卡片右侧的操作按钮：
- **分类与标签**：为人设归类、打标
- **编辑**：弹窗编辑显示名 + 描述，保存时**按 ID 锁定写入**，不会写错人设
- **删除**：先将名称、描述和备注放入回收站，再删除头像文件与关联设定。回收站默认保留 30 天；恢复文字后，头像需要重新上传。

### 采纳与缝合

- 对比页的「采纳」会打开完整预览，可以润色片段、选择写入方式及锚点。
- 「替换选中」仅移除勾选的行或片段，在第一个选中位置插入一次；中间未选的内容保留。
- 缝合支持按段落/按行选择，或直接编辑全文。箭头只更新草稿，点击「保存修改」才写回。
- 草稿中的操作支持撤销/重做；原始缩进、空行和换行符在片段操作中保留，全文编辑也保留未改部分的换行格式。
- 别处已改动的人设会停止写回；编辑、采纳、缝合均自动保留草稿，暂存关闭后可继续。

### 草稿、历史和来源

- 编辑后自动保留，关闭窗口时暂存。重新打开同一人设或在「资料」页点击恢复，先比较当前版本与草稿，再恢复到编辑窗口；点击保存才写回酒馆。
- 缝合草稿记录双方内容、片段选择、模式和来源；交换双方顺序再打开，也按人设 ID 恢复。
- 如果采纳的基准已被原生编辑修改，恢复时先展示完整对照，并把旧草稿作为新的全文候选，避免沿用失效的行号。
- 每次写回前后保留版本。在编辑窗口的「历史与来源」或资料页「查看与回退」中，选择版本并检查对照后恢复。回退也会产生新版本。
- 采纳、缝合和字段合并记录当时的来源 ID、名称、原片段、写入方式和时间；撤销的操作及失败的写回不记为已保存来源。
- 最多 30 份草稿；每个人设最近 40 个版本，全部人设合计最多 1,000 个版本、1,000 条来源。资料总量接近 800 万字符时优先清理旧版本；草稿不会被静默丢弃。

### 字段级缝合

在缝合工作台点击「字段缝合」，选择目标和格式，逐项处理字段。冲突默认保留目标；「采用新增字段」只勾选来源中新增的字段。应用后只修改缝合草稿，仍可撤销；最后在主缝合窗口点击保存。

- Markdown：识别 ATX 标题（# 至 ######）及层级；代码围栏中的示例标题不会当成章节。
- YAML/JSON：识别嵌套映射；数组作为一个字段处理，字段名区分大小写与空格。手动值使用 JSON 表达式，Markdown 手动值为普通正文。
- 不改动的结构和文字尽量逐字保留；被修改的 YAML 值会写成合法的 JSON 流式值，块文本/数组的排版可能改变，完整结果可在保存前检查。
- 含锚点、别名、复杂键或不安全结构的 YAML 会停止自动应用，可返回段落或全文模式。字段模式限制 200 万字符、1,500 个字段/章节。
- 字段窗口里的选择在「应用到缝合草稿」后才进入自动草稿；未应用的临时选择不跨刷新恢复。

### 备份与导入

「资料 → 导出完整备份」下载 JSON，包含标签、分类、回收站、主题设置、工作草稿、版本、来源和当前人设文字/备注。头像图片不包含在内。

导入先显示数量，再选择合并或替换本地资料；是否导入主题和界面配置单独勾选。名称相同的标签/分类复用，ID 冲突会重映射；重复导入相同记录不会再次添加。备份中的人设文字作为历史快照保留，需要在历史中逐份确认恢复，不会在导入时直接覆盖现有人设。文件限制 50MB，超过草稿容量会停止导入。

### 主题与配色

设置中有粘土拟态 Claymorphism、吉卜力风格 Ghibli Style、水彩艺术 Watercolor Art、少女漫画 Shoujo Manga。四种风格分别使用浮雕软阴影、森林纸感、晕染背景、网点与漫画边框。

可分别调整主题色、背景色、卡片色、文字色，实时预览并按风格保存；「恢复此风格配色」只清除当前风格的配色。文字色会根据卡片色修正明显不足的对比度。旧主题设置会迁移到对应的新风格。收藏页原先的标题、英文与介绍文案已移除。

## 移动端

v1.8.13 起在手机浏览器（非全屏和全屏）做了适配：

- 使用 `100dvh` 解决浏览器地址栏导致窗口塌陷
- 入口按钮 `pointer-events: auto` + 提高 z-index 修复全屏点不动
- 主窗口铺满手机屏幕，编辑器支持弹窗和全屏
- 编辑器跟随可视区域高度与偏移，键盘弹出后仍保留保存按钮
- 键盘中优先展示正文，「名称」可随时展开；极短视口将保存移至顶部
- 原生归类按钮与筛选面板同步当前主题，「清除筛选」横排显示
- 对比页改整页滚动、基准/对象按钮缩小、共同片段独立滚动
- 卡片双列 / 单列自适应
- 手机缝合改为上下两份人设同时显示，各自独立滚动；箭头显示写入上方/下方
- 小屏主工作台保留双方操作区与保存栏；完整结果和前后差异通过「结果预览」打开
- 正文优先占据屏幕，次要工具按需展开；每侧可点「放大」选择片段或编辑全文，再返回同一缝合草稿
- 竖屏上下排列，手机横屏可用足够宽度并排；段落/逐行/全文可直接从每侧标题行切换
- 同名及重复分组均可完全收起到标题栏，包含 2～4 份人设的小组；展开恢复完整卡片，折叠时仍能全选整个组

## 配置

设置存在 `localStorage["pmp18_settings"]`：

| 字段 | 默认值 | 说明 |
|---|---|---|
| `similarityThreshold` | `0.55` | 高度相似阈值 |
| `softMatchThreshold` | `0.35` | 段落匹配敏感度 |
| `includeSameNameInSimilar` | `true` | 同名是否参与"高度相似" |
| `showDiffOnly` | `false` | 对比页只显示差异段 |

标签、分类、回收站与各风格配色也存放在同一个键中。草稿、版本和来源优先保存在 IndexedDB；宿主提供 accountStorage 时为资料库分配账户标识，否则按当前网站存储。IndexedDB 不可用时回退到 accountStorage/localStorage。输入时另写临时日志，刷新后恢复最近编辑。

清理网站数据或更换浏览器会丢失这些本地资料；重要内容请导出 JSON。账户标识不代表跨设备同步。存储失败会显示错误，并停止需要资料保护的写回。草稿已满时，等待恢复的临时编辑会保留；在资料页删除一份已完成草稿后再恢复、导出。

只重置界面和匹配选项、保留组织资料：

```js
const settings = JSON.parse(localStorage.getItem('pmp18_settings') || '{}');
Object.assign(settings, {
  similarityThreshold: 0.55, softMatchThreshold: 0.35,
  includeSameNameInSimilar: true, showDiffOnly: false,
  editorMode: 'popup', uiTheme: 'shoujo',
});
localStorage.setItem('pmp18_settings', JSON.stringify(settings));
location.reload();
```

## 更新

扩展设置里有「检查更新」按钮。自动检查仅获取版本信息，共享并发请求，并缓存 15 分钟；打开日志窗口时再获取 CHANGELOG。手动检查可立即重试。

- 扩展目录通过 `git clone` 安装时：一键自动 `git pull`
- 扩展目录通过 zip 解压安装时：会提示失败并给出 GitHub 手动下载指引（v1.8.12+）

## 兼容性

- SillyTavern ≥ 1.13（需要 `power_user.personas` / `persona_descriptions` 字段）
- 移动浏览器：需要支持 `100dvh`、ES modules 和 Visual Viewport 的现代浏览器。已检查 Chromium 手机视口与模拟键盘布局；Safari / Android 真机集成仍待验证。
- 桌面浏览器：现代浏览器即可
