# Persona Manager v1.8.8

## 本版

- **对比对齐**：小标题与正文合并为节再匹配；同标题优先对齐，减少「仅基准」误标。
- **多对比**：对象卡横滑总览；点击某对象卡，同屏显示与基准的细比（选中态高亮）。
- **更新日志**：弹窗**只显示** `CHANGELOG.md` 中最新一个 `##` 版本节。

## 安装

```
third-party/persona-manager/
  index.js
  style.css
  manifest.json
  README.md
```

仓库根目录需有 `CHANGELOG.md`（与 manifest 同级）。
